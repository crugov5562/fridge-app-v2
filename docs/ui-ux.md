UI/UX правила — FridgeAI
You are an expert in mobile UI and UX design for FridgeAI — приложение учёта продуктов с ИИ. Стек: React Native + Expo + NativeWind. Читай этот файл перед любой UI-задачей.
Визуальная идентичность
FridgeAI выглядит как пересечение двух референсов:

Структура и контент — как EcoCart: цветной hero-блок, группировка по категориям, FAB по центру таб-бара, статусные бейджи срока годности.
Эстетика и типографика — как первый референс: белый фон, много воздуха, крупные жирные заголовки, карточки без тяжёлых теней, pill-кнопки.

Акцентный цвет — изумрудный зелёный. Один акцент на всё приложение. Нигде больше нет ярких цветов кроме семантических статусов.

Core Philosophy

Less, but better. Каждый видимый элемент оправдывает своё присутствие — если нет, удали.
Content is the interface. Фото продуктов и блюд — главные визуальные элементы, не декорации.
Clarity over cleverness. Пользователь не догадывается, он сразу понимает.
Consistency builds trust. Одно действие выглядит одинаково везде.
Motion has meaning. Анимация коммуницирует состояние, не украшает.

Ключевые UI-паттерны
Hero-блок (главный экран)

Изумрудный фон (emerald-100 светлая / emerald-900 тёмная)
Приветствие с именем, Heading L, белый текст
Два pill-бейджа: «8 продуктов» и «2 истекают»
Switcher холодильника с chevron
Скруглённые углы снизу (rounded-b-3xl)

Карточки продуктов

Горизонтальная строка: фото 48×48 rounded-xl → название + категория + количество → статус бейдж
Группировка по категориям с заголовком и счётчиком
Разделитель 1px между строками
Свайп влево: «Использовал» (изумрудный) / «Выбросил» (красный)

Статусные бейджи срока



5 дней: зелёный фон + иконка clock + текст «5 дней»


1–5 дней: янтарный фон + иконка alert-triangle + текст «Истекает завтра»
Просрочен: красный фон + иконка alert-circle + текст «Просрочен 2 дня»
Всегда иконка + текст, не только цвет

FAB — сканирование

По центру таб-бара, поднят на 16pt
Изумрудный круг 56×56pt, иконка scan-line белая
Тап → bottom sheet: «Сканировать чек» / «Сфотографировать» / «Добавить вручную»

Таб-бар

5 позиций: Главная | Рецепты | [FAB] | Сроки | Профиль
Активный таб: изумрудная иконка + изумрудный label
Неактивный: серая иконка
Белый фон, 1px верхняя граница

Карточки рецептов

Фото блюда вверху, полная ширина, height 160, object-cover
Название Heading M, время, прогресс ингредиентов
Прогресс-бар изумрудный «4 из 5 ингредиентов»
rounded-2xl, фон card, без тяжёлой тени

Кнопки

Primary: pill (rounded-full), чёрный фон, белый текст, высота 52pt
Secondary изумрудная: pill, emerald-500 фон, белый текст
Ghost: прозрачный фон, изумрудный текст и border
Destructive: красный фон или красный текст


Visual Design

Белый фон, много воздуха. Минимум декоративных элементов.
Карточки без тяжёлых теней — лёгкий border или тонированный фон.
Фото продуктов и блюд — главные акценты. Всегда rounded-xl или rounded-2xl.
Один радиус: rounded-2xl карточки, rounded-xl элементы внутри, rounded-full кнопки и бейджи.
Иконки: только lucide-react-native, strokeWidth 1.5.
Dark mode обязателен. Каждый токен имеет dark: вариант.

Interaction Design

Одно primary action на экран.
CTA глаголом: «Добавить», «Сканировать», «Приготовить».
Touch targets минимум 44×44pt.
active:opacity-80 или active:scale-95 + expo-haptics на каждом тапе.
Анимации ease-out вход, ease-in выход, 200–350ms.
react-native-reanimated worklets + moti. Никакого legacy Animated.


Accessibility

accessibilityLabel, accessibilityRole, accessibilityHint на каждом интерактивном элементе.
Статусы: цвет + иконка + текст. Никогда только цвет.
Dynamic type: относительные размеры Tailwind.
WCAG 2.1 AA минимум.


Performance

expo-image для всех изображений с явными width/height.
@shopify/flash-list для инвентаря и рецептов.
renderItem и обработчики через useCallback.
Skeleton повторяет финальный layout.
LLM ответы стримятся, не блокируют UI.


User Feedback

Loading: skeleton повторяет layout строк инвентаря и карточек рецептов.
Success: тихий toast снизу для ожидаемых действий.
Error: что случилось + что делать + retry. Никогда стек трейс.
Empty state: иконка + заголовок + одно действие.

Пустой инвентарь: «Холодильник пуст» → «Сканировать чек» (изумрудная pill) + «Вручную» (ghost)
Нет рецептов: «Добавь продукты» → «В инвентарь»


Destructive: bottom sheet «Выбросить молоко?» + «Выбросить» (красный) + «Отмена»


AI Interface Patterns
Сканирование

Camera preview с рамкой и подсказкой.
После снимка: затемнение + статусы «Читаем чек...» → «Определяем продукты...» → «Готово».
Экран подтверждения — каждую позицию можно редактировать.
Низкая уверенность → жёлтый бейдж «Проверьте» на позиции.
Ошибка → конкретное сообщение + retry + «Ввести вручную».

Рецепты RAG

Thinking indicator: тонкая изумрудная линия анимации сверху.
Стриминг объяснения токен за токеном.
Покрытие: ✅ есть / ⬜ нет / 🟡 заканчивается.
Кнопка «Другие варианты» всегда доступна.
Collapsible «Почему этот рецепт».

Голосовой ввод

Большая круглая кнопка записи, изумрудная, пульсирует во время записи.
Транскрипт сразу после остановки.
Редактирование перед отправкой.
Таймер 60 сек с круговым прогрессом.

Уведомления

Человеческий текст: «Молоко истекает завтра. Приготовь блинчики?»
Тап → экран рецептов с этим продуктом.
Утренний дайджест одним уведомлением.


Forms

Нативные типы клавиатуры.
Валидация on blur.
Ошибка: красный текст + иконка alert-circle под полем.
Auto-focus первого поля, auto-advance через returnKeyType.
react-hook-form + zod.
DatePicker нативный, умный дефолт по категории.


Что не делать

Хардкоженые цвета и размеры вне tailwind.config.js.
Более одной primary кнопки на экран.
Декоративные градиенты и тяжёлые тени.
Смешивать UI-библиотеки.
Пропускать empty, loading, error states.
Generic спиннер вместо skeleton.
Long-press как единственный способ действия.
«AI думает» дольше 2 секунд без прогресса.
Яркие цвета кроме изумрудного акцента и семантических статусов.
Больше трёх типографических уровней на экране.
